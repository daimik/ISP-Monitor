Client commands

TCP — basic upload
iperf3 -c <server-ip> -p 5201
TCP — download (reverse)
iperf3 -c <server-ip> -p 5201 -R
TCP — 4 parallel streams
iperf3 -c <server-ip> -p 5201 -P 4
TCP — bidirectional
iperf3 -c <server-ip> -p 5201 --bidir
TCP — 30-second test
iperf3 -c <server-ip> -p 5201 -t 30
TCP — 10 streams, 30 s, reverse
iperf3 -c <server-ip> -p 5201 -P 10 -t 30 -R
UDP — unlimited bandwidth
iperf3 -c <server-ip> -p 5201 -u -b 0
UDP — 100 Mbps target
iperf3 -c <server-ip> -p 5201 -u -b 100M
UDP — download (reverse)
iperf3 -c <server-ip> -p 5201 -u -b 0 -R
UDP — 1 Gbps, 30 s
iperf3 -c <server-ip> -p 5201 -u -b 1G -t 30

Flag reference

FlagDescription
-c <ip>Connect to server at this address
-p <port>Server port (default 5201)
-t <sec>Test duration in seconds (default 10)
-P <n>Number of parallel streams (default 1)
-RReverse mode — server sends, client receives (measure download)
--bidirBidirectional — test upload and download simultaneously
-uUse UDP instead of TCP
-b <rate>Target bandwidth: 0 = unlimited, 100M = 100 Mbps, 1G = 1 Gbps
-i <sec>Reporting interval in seconds (default 1)
-JJSON output (useful for scripting)
-w <size>TCP window size / socket buffer (e.g. 512K, 4M)
-l <size>Read/write buffer length (default 128K TCP, 8K UDP)
Install iperf3 on the client:
Debian / Ubuntu: sudo apt install iperf3
macOS: brew install iperf3
Windows: download from iperf.fr
